W05 Project: Website Planning Document

Site Name:

SJQuality - sjquality.com

An introductory website about software testing and quality assurance.

Site Purpose:

The site explains different types of testing, common testing tools, testing career paths, and include a glossary of QA terminology. Visitors could filter testing types by category and submit questions through a contact form.

Scenarios:

What is the difference between manual testing and automated testing?

Which software testing tools should I learn first?

What is the difference between regression testing, smoke testing, and sanity testing?
